# Week 3 - Advanced Data Analysis and Visualization in Logistics

## Objective
Explore a hypothetical logistics dataset, calculate descriptive statistics and correlations,
create visualizations, and derive operational insights.

## Dataset
`data/hypothetical_logistics_dataset.csv` is a simulated logistics dataset created specifically
for this academic task. It contains 360 shipment records with delivery time, shipment volume,
distance, transport mode, priority, transportation cost, handling cost and late-delivery status.

## Analysis performed
- Central tendency: mean and median
- Distribution analysis
- Regional and transport-mode comparisons
- Correlation analysis
- Monthly shipment-volume trends
- Distance vs. delivery-time relationship
- Logistics KPI interpretation

## Visualizations
1. Delivery-time histogram
2. Average delivery time by transport mode
3. Average logistics cost by region
4. Distance vs. delivery time scatter plot
5. Monthly shipment-volume line chart
6. Correlation matrix

## Run
```bash
pip install -r requirements.txt
python week3_logistics_analysis.py
```

## Important note
The dataset is hypothetical/synthetic and is not presented as real company performance.
The insights in the report demonstrate how an analyst would interpret logistics data.
